# Retrospective reporting protocol

Inputs: complete result.json and traces of integrate-enclosure-session-20261012 (88 episodes) and select-enclosure-structure-20261012 (96 episodes), calibration files, original implementation and existing verification records. Hash all historical study artifacts before work. Exclude none of the declared study episodes from metric verification. Do not run study executors or fit controllers.

Recompute existing n, source MAE/RMSE, prediction MAE/RMSE, tracking MAE, maximum source, sampled overtemperature, command variation, fan proxy, warning/fallback counts and timing from each stored CSV. Check CSV hashes, declared macro aggregates and old decisions without replacing source files. Graphs summarize existing metrics only. Per-platform tables retain both seeds; do not claim confidence intervals or significance from four holdout pairs.

Mechanism language: distinguish an implementation fact, a descriptive result, a compatible explanation and a future causal test. No post-hoc mechanism is an adopted new claim. Preserve all adverse comparisons.

Conference source checks on 2026-10-19: official submission page and original Chinese full-paper PDF template. CSME target format is only a candidate; author metadata comes from existing manuscript and final author consent is not inferred. Keep an external review-readiness note. Final acceptance: numeric checks, historical hash integrity, source links, offline HTML 1440/820/390px, keyboard/overflow checks, observed screenshots, 4-6 page PDF under 10 MB with A4/margins/fonts and complete page inspection. No external submission.
