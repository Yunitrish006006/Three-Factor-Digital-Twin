# Design
BPT-001 / RQ-BPT-01..03: use a separate copied FMI lifecycle adapter with explicit outgoing-actuator observation before overrides. Supply value is valid before activate. Extend PI with handover initialization and a past-transition disturbance observer; preserve legacy PI as comparator. Metrics use true temperature, measurements get reproducible common noise. Source hash freeze enforced between development/transfer, each run refuses overwrites. Calibration budget remains 2h prefix (originally 6h was collected); this round adds simulation evaluation and development overhead. Neural network still untested.

Implementation detail / protocol clarification recorded before transfer: the observer returns the heat-equivalent handover command explicitly at k=0, sets disturbance=-b*(u0-T0), and starts its remaining integral at zero. Thus the first action is exactly aligned, while the internal integral is not algebraically matched to the subsequent bias at nonzero initial error. This differs from the protocol's phrase “align integral to bias”; no hidden initial integral optimization occurred. Both behavior and resulting startup error are retained and independently tested.
