# BPT-P1 protocol (before new simulations)
Pin original BOPTEST v0.9.0 and 2h fit from prior pilot; preserve original runner/evidence hashes. Reuse 60s cadence, 22C target, 12–40C supply, external fan=0.5, fresh FMU and 24h embedded warmup. No new identification data. This round scores all 24h including initial transient. Units are simulated days; no IID minute-level confidence intervals.
Development days 3/180: run four controllers: exact v2 PI (cold integral), v3 same PI with heat-equivalent bumpless initialization, v4 v3 plus disturbance observer, and grid PI Kp=6/Ti=300 with identical bumpless initialization. Handover reads outgoing room/supply/fan, maps supply_new=T+fan_old/0.5*(supply_old-T), clips, sets initial integral so first command equals this value. This is an approximate sensible-heat continuity rule, not exact enthalpy conservation.
Observer candidate uses b from 2h fit. At each time k>=1, estimate disturbance z=(T_k-T_prev)-b*(u_prev-T_prev); exponential update d=0.8*d+0.2*z. Feedforward bias=22-d/b; same PI gains and antiwindup as v3. Initialize d=-b*(u_initial-T_initial), align integral to bias. No future weather or temperature; no online gain fitting. Observer initialized separately for every episode.
Select v3 or v4 by lowest mean development MAE subject to each day's MAE<=v2+0.01 C and maximum error<=v2+0.1 C. If neither qualifies retain v2, report rejection. Ties prefer v3 simplicity. Record selection and source hashes BEFORE new dates. Do not retune after opening new dates in this round.
Transfer phase (not previously inspected): days 35,95,245,305 clean; days95,245 with deterministic Gaussian sensor noise std0.05 C (seeds=42000+day; common noise sequence per controller). Same three controllers: old v2, selected candidate, grid with bumpless handover. Noise is added to measured room temperature only during control, not simulator ground truth. Initial outgoing room measurement also receives the first noise sample; no duplicate draw. Target and all metrics scored against true temperature. No actuator delay in this round. These are fresh-date simulation checks within the SAME model/weather year, not cross-building or real confirmation.
Primary decision: macro paired MAE improvement vs v2 >0, MAE no worse by >0.01 C in any of six cases, max error no worse by >0.1 C in any case. Against grid: display signed gaps and exploratory margins +0.05 C MAE/+0.5 C max error; do not claim equivalence from margins alone. Report initial30min and remaining-period MAE, full MAE/RMSE/max error, +-0.5C fraction, separate energy channels, actuator variation/saturation and out-of-domain count. Retain failures and all adverse/noisy cases; if a phase fails mark failure without overwriting it.
Output artifacts/development.json, selection.json, transfer.json and CSV under outputs/boptest_transfer. Producer scripts/run_boptest_transfer.py --phase development then --phase transfer. Before opening transfer freeze file hashes in selection.json. Algorithm changes afterwards require new version and evaluation cases.
