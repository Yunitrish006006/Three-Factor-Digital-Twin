# Design
MCC-001 uses the full ARX one-step innovation, ten-step input/disturbance response, and regularized limited authority. A native adapter supplies only currently observed outdoor temperature and records causal diagnostics. Existing ARX bank and physical adapters remain frozen. The new five-plant JSON reproduces existing installation overrides, not a newly tuned environment. No NN or optimizer is added. ResearchWorkspace will link methods, datasets, studies, comparisons, failed gates and local report/evidence as separate typed entities, preserving paper-first hierarchy.
