# Design

LDA-901 maps RQ-LDA-1/2 to a read-only composition of existing fitting, sparse observer and SessionController. Research-only instrumentation computes unconstrained feedback separately and checks agreement with unchanged commands. LDA-902 verifies complete CSVs and oracle access. LDA-903 creates common result-derived summaries for synchronized research artifacts and a concise HTML explanation; original experiments and original review version remain traceable in Git. No physical actuator/network API is invoked.
