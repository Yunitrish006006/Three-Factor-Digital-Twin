# Unified five-controller comparison
使用者要求在同一機箱環境直接比較 fixed PWM、PI、PID、LQR、MPC。建立獨立研究批次；保留 10/05、10/06、10/19 凍結證據。新方法差異是 plain PI/PID 使用固定偏置 .6 而無 model feedforward；LQR/MPC 保留各自模型式原理。所有方法收到相同 full-state observation/inlet/power、限制及調參候選回合預算。主張屬探索性新增模擬證據，不提升硬體或泛化證據層級。同步 thesis source/builder/DOCX/PDF、IEEE source/PDF、presentation outlines/builder、教授離線 HTML/CSV/ZIP；依 AGENTS 新教授報告採 HTML 並保留歷史 PPTX。
