# Frozen protocol — before any calibration/evaluation
UFC-001. 完整數值輸入為 config.json。相同 CPU/GPU 雙節點方程 C_i dT_i/dt=P_i-(G_i+k_i f)(T_i-Tin)，df/dt=(u-f)/tau；1秒 Euler heat/exact fan；每10秒控制一次、120步、1200秒。目標60/60°C、警告75/80°C、限制80/85°C、初始T=[58+seed%3,59+seed%3]、fan/PWM=.5。PWM [.2,1]、每步slew .1。所有方法共享目前完整真實state/inlet/power，不給未來；這是 controller-only full-state 比較，非稀疏感測驗證。
UFC-002. fixed/PI/PID/LQR/MPC 各3候選×3 calibration seeds=45校準回合。PI/PID共同固定偏置.6，error=max(Tcpu-60,Tgpu-60)，I增量ki*error*10，PID derivative為alpha=.25低通的(error-prev)/10；PI kd=0。backcalculation=.2；沒有equilibrium feedforward。LQR使用既有受限gain-scheduled local ZOH/DARE Qdiag(.04,.04,0)、候選R；MPC使用同名義參數、horizon12/Q1/25/delta5/slack1e4與既有OSQP residual gate1e-5。相同候選回合數不代表相同搜尋空間／CPU預算或全域最佳。
UFC-003. calibration score=mean(error²/25)+.01mean(u³)+1e4mean(positive_limit_violation²)；3seed等權、候選索引tie-break，禁止逐plant手調。校準前保存preregistration及所有研究來源快照，校準後freeze selected及CSV hashes，evaluate前核對完全一致。validation/holdout/plant_holdout/overload各3seed×5方法=60正式回合/7200步；總105回合/12600步。每個seed/分組五方法輸入完全相同，方法依固定順序執行，計時只作實作負擔描述，非控制器速度因果排名。
UFC-004. 每段負載採i*段數//120索引；CPU/GPU各uniform±5/8W，Tin=29+(seed%3-1)+1.5I(i>=40)+.5I(i>=80)+uniform[-.2,.2]。config指定新的負載與seed。plant_holdout三variant依seed順序一一配對，controller始終只用名義參數；僅為指定同族壓力測試，不宣稱未知硬體泛化。overload440/580W，保留超溫結果。
UFC-005. 每步共同warning/failure ramp-to-max、PWM及slew限制；控制計時>=10秒則fallback並保留deadline。報next-state CPU/GPU與雙節點MAE/RMSE、每回合峰值與全體最大值、any-node sampled-overtemp(10秒末端×dt)、bounds/slew/fallback/warning/deadline、命令TV及10*u³W能耗proxy。非整機/實測功率。分組按3episodes等權；不跨split平均排名；列每seed值與MAE次序、energy以及Pareto(MAE/energy/overtemp三者最小)。無單一通用勝者假說，任何排名都附完整設定、代價與失敗。
UFC-006. attempt marker及CSV使用exclusive create；中斷也消耗，不覆寫或偷偷重跑。如需修正，保留失敗紀錄另立版本協定。sources/config/protocol校準前固定。獨立stdlib verifier不匯入runner/controller，重算全部核心指標、每步Euler/exact fan、scenario、共同輸入與initial、candidate score/selection、聚合/Pareto、freeze及歷史hash；負面測試拒絕tampered result和trace。容許1e-8 abs/1e-7 rel（dynamics 1e-7）；count完全相等。測試僅使用非研究fixture seed102699。
