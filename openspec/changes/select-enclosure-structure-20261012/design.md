# Design

ENC-701 adds a versioned calibrated_session module with ThermalPathParameters, a balanced source-air heat exchange, compatible sparse observer and unchanged PI/H6 control mechanism. It does not edit any frozen module or replace the public v1 session.

ENC-702 selects S/F using a chronological commissioning holdout and two bounded fits; observed channels only. A dedicated CSV entrypoint produces offline proposals and a model manifest. Source-reference comparison uses the existing independent scorer.

ENC-703 executes a new one-shot study, independently verifies trace and selection completeness, records failure/saturation and preserves old artifacts. This is small-data commissioning-assisted model selection, not hardware or zero-shot transfer.

SYN-701 updates the same professor HTML with an explicit second-stage section, date/evidence separation and the exact positive/adverse conclusions. Retain prior failed hypotheses and the LQR paper. Coupled scientific sources/outputs keep the same exploratory scope through native builds; Office rendering is outside this turn.
