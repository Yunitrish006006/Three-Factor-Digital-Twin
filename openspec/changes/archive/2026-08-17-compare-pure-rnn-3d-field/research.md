# Research Framing

## Research Question

| ID | Question | Type |
| --- | --- | --- |
| `RQ-RNN3D-01` | 在相同八情境、相同八顆稀疏觀測與相同 leave-one-scenario-out 測試場下，不使用 physics estimate 的 pure Elman RNN，其 full-field MAE 相對 IDW、base model 與 LOO hybrid 為何？ | exploratory |

## Hypotheses

No directional superiority hypothesis is registered. `CLM-RNN3D-01` requires a complete, parity-audited same-task comparison and preservation of adverse results, not a favorable RNN result.

## Construct Operationalization

| Construct | Operational definition |
| --- | --- |
| pure RNN | one vanilla Elman recurrent model plus linear three-output head; no physics estimate, residual target, IDW prediction, or held-out dense truth in its inputs |
| sensor sequence | the eight input-role corner sensors in canonical scenario order; each token contains normalized sensor coordinates and observed temperature, humidity, and illuminance |
| query context | query coordinates, room baselines, outdoor boundary values, elapsed time, and current device activation/power, repeated for every sensor token |
| training unit | one sampled dense-field query point from one of seven training scenarios |
| test unit | one full-grid query point from the held-out scenario |
| data parity | identical scenario folds, sparse observation payload, held-out truth field, metric implementation, and query grid across all four methods |

## Intended Claim

`CLM-RNN3D-01`: IDW, base model, pure Elman RNN, and LOO hybrid residual were compared on the same eight canonical controlled scenarios, sparse observations, held-out scenario folds, query grids, and dense synthetic truth. The result is a controlled same-task comparison only.

## Competing Explanations and Threats

- Dense truth and sparse observations are generated by the same controlled simulator family.
- Eight scenarios provide few independent device-state combinations, so a pure RNN may underfit or memorize regularities.
- Sensor order is canonical but recurrence over spatial sensor tokens is an architectural convention, not a physical time sequence.
- Base and hybrid models contain explicit inductive structure; pure RNN performance depends on fixed capacity and preprocessing.
- One room geometry, one sensor topology, and one furniture arrangement do not establish cross-room transfer.
- Full-field MAE includes grid points colocated with sparse sensors, consistently for all methods.

## Ethics, Privacy, and Safety

This controlled experiment introduces no human-subject data and actuates no physical device. It uses only repository-generated synthetic scenarios and preserves the existing 20–30 °C applicability boundary.
