# Development protocol v1 — specified before simulations
Experiment BPI-P1 uses official BOPTEST v0.9.0 bestest_air wrapped.fmu, commit 9b1610bf7a108826bb3d22c72bffd2d71d7bb0a9. Use FMPy 0.3.22 FMI2 co-simulation directly; this is NOT official REST/KPI benchmark equivalence. Record FMU hash, source license and all failures.
Sampling 60 s, room target 22 C. Supply bounds 12–40 C and fan 0.5 for every external controller. Embedded reference overrides heating/cooling target to 22 C; its own fan modulation remains active and it is contextual only. Each episode starts a fresh FMU, with 24 h embedded-controller warmup using the same target. Warmup is common and excluded from score and active calibration budget, but reported.
Identification begins day 1: 6 h, deterministic 15-min blocks of supply 22 + [-4,8,0,12,-8,4] C repeating. Fit first 2 h and full 6 h separately. Model: delta T = a(Tout-T) + b(Tsup-T) + c solar/1000 + d. Ridge only for numerical conditioning. Reject nonphysical a<=0, b<=0 or a+b>=1; safe fallback fixed PI, failures visible. PI time constant from discrete first-order model; IMC target response 600 s. Conditional integration anti-windup and actuator limits mandatory. Compare auto PI alone and auto PI plus environmental feedforward for each budget. Existing h=0 neural weights not transferable; add no NN unless a later development revision demonstrates need.
Fixed PI Kp=2, Ti=1200 s. Grid PI Kp in [0.5,2,6], Ti in [300,1200,3600] s: each evaluated for 6 h starting day 1 after warmup, minimize MAE (ties ordered by grid order). Grid budget is 9 x 6 = 54 simulated control h, not human labor. Fixed PI budget=0 (expert preset, not free knowledge). Training and grid traces are development data only.
Evaluate all controllers on day 3 and day 180, 24 h each, with fresh previous-day warmup. These are development evaluation dates, NOT a sealed confirmatory test; no CI with two deterministic cases. Report every case and temperature domain violations. Primary metrics full-period tracking MAE/RMSE, time within +-0.5 C, max absolute deviation, absolute-error integral C*h. Energy channels separate heating thermal (as labelled by FMU), cooling electrical, fan electrical; no unqualified total-energy claim. Actuator saturation and total supply-temperature variation secondary. Do not select based on validation then call it confirmation.
Feasibility gate: auto method MAE <= fixed PI on BOTH dates, without worse max error by >0.5 C. Stronger reduced-tuning claim remains NOT_EVALUATED pending multiple plants/seeds, equivalent budget curves and independent evaluation. Preserve adverse results, failed identification and all out-of-domain rows; no silent exclusions. A failed FMU blocks numeric outcomes.
