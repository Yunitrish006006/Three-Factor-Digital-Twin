# DGA-001 Descriptive protocol
Use all final MCC-001 plant results, verification and their canonical calibration CSVs. No new simulation or fitted model. Group plant/budget as both-date positive MAE gains, both-date negative gains, mixed signs, exact ties, or identification rejected. Keep numerical gains and original overall gate separately; tiny numerical losses are not relabeled ties. Extract selected order/delay/time-scale, 10-step input response, calibration validation RMSE, response-to-uncertainty score, calibration temperature span and normalized input range, covariance condition only if recorded (do not invent). From both evaluation traces summarize actual correction magnitude, fraction hitting correction bound, confidence range, innovation signed mean/RMS, temperature change range, saturation and error on/off saturation. Distinguish heuristic model-based quantities from physical plant constants. Display every group, no p-values/regression with five heterogeneous FMUs. Any proposed mechanism is a hypothesis; no threshold chosen from these data is applied to control. Freeze input hashes and write artifacts/device_groups.json. Offline report and ResearchWorkspace group nodes reference exact artifact pointers.
