# Planning protocol — not yet executable

Canonical detail: docs/research/application_goals_2026-09-08_zh.md. APP-FIL-01 starts with 20–30 C storage/feed; heated drying is out of the existing domain. Printer/material compatibility, reference instrumentation, humidity range, logging cadence, equilibration rule, durations and quality tolerances remain unresolved; freeze them before acquiring confirmatory outcomes.

Suggested pilot: 3 independent conditioning batches per storage arm, 2 specimens per batch, only to assess measurement feasibility/variation. Use common drying pretreatment, exposed storage, sealed desiccant storage and active storage. Block/randomize treatment and print order. Independent conditioning batches, not per-second rows or co-printed objects, define treatment replication. Later controller comparison uses identical hardware with fixed targets, conventional feedback and candidate control.

Primary candidate endpoint: passed specimens / all started specimens; success requires completion and predeclared dimensional/visible-defect requirements. Report completion separately. Mechanical strength only with appropriate equipment/protocol. Keep failures in denominators; prospectively defined external-invalid events retain logs and all-started/analysis counts. Continuous quality errors supplement, not replace, prespecified yield. Energy boundary includes pretreatment, storage and printing per accepted specimen; zero accepted specimens is undefined, not zero energy.

Select formal sample size and minimal relevant effect from pilot and batch variability. Split by independent batches; do not reuse E15. Baselines include fixed setpoint control; absence of gain is an acceptable outcome. Downloadable licensed raw material data are not confirmed; self-collected records require provenance, calibration and timestamps. Before execution add a dedicated runner and machine-readable record schema; do not create empty result files or invented evidence now.
