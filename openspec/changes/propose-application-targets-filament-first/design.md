# Design

APP-001 maps RQ-APP-01–03 to an offline HTML proposal briefing and a canonical goals document. The generator reads frozen E15 JSON for displayed existing numbers, embeds all slide assets locally, provides keyboard navigation, overview, presenter notes and print CSS. Report source contains no new outcome values. A manifest hashes evidence and HTML.

Learning is an optional extension; simple constant-target feedback is an explicit competitor. ResearchWorkspace graph schema and current experiment inventory are unchanged by this report; no proposed outcome becomes a validated graph node.
