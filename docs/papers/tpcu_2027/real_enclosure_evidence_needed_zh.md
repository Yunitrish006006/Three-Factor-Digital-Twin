# 改用真實機箱資料的最低證據條件

目前投稿稿件的105個回合來自假設雙熱源模型，不能改稱實機測試。要將研究主張改為「真實機箱五策略比較」，需另建立有來源的實體試驗；下列項目尚未由本專案的現有資料滿足。

已知預定場域為一般大樓房間，有一扇對外窗、機箱位置無直射日光，保持通風且無冷氣或風扇直吹進氣口；平常觀察室溫約24–26°C，尚無連續紀錄。這些是場域描述，不等於已測得機箱進氣口溫度均一；原模擬入口溫度另由約29°C的預設公式及階躍擾動產生，不能當作該房間量測。

1. **設備與幾何**：記錄機箱、CPU、GPU、散熱器、風扇、風道、主機板與韌體版本，附測點位置及照片；固定側板、環境與風扇接線。此項用來界定比較對象，避免不同設備混為同一實驗環境。
2. **同步原始量測**：每個時間戳保留CPU/GPU溫度、進氣溫度、CPU/GPU功率、PWM命令、實際RPM、風扇電壓與電流、環境溫度、工作負載狀態；保留儀器型號、校正紀錄、取樣率、單位、缺值與原始檔雜湊。若缺風扇電功率，只能報PWM或RPM，不能報實測節能。
3. **模型辨識**：用一部分實測階躍或負載變化辨識熱容量、等效熱導及風扇延遲，另保留獨立資料檢查預測誤差。不得將本稿假設的C、G、k、tau直接稱為實測參數。
4. **共同控制協定**：五種策略在同一台機箱、相同工作負載序列、入口條件、PWM/RPM限制與保護機制下比較；事先固定校準與測試分組、參數搜尋預算、試驗順序和重複次數。採交錯或隨機順序並設冷卻回復條件，降低時間與熱殘留偏差。
5. **安全與失敗紀錄**：設定韌體或硬體獨立保護、人工停止條件、溫度上限與回退；完整保留超溫、限幅、求解失敗、降頻與中止回合。不可只選成功回合報告。
6. **重算論文**：以原始實機記錄重新計算每策略的溫度誤差、超溫時間、實測風扇能耗與不確定性；重畫圖表，更新摘要、方法、結果與結論。原模擬表三／表四不得直接移作實機結果，可另列為先前模擬比較。

原始機箱資料與設備資訊取得前，現有PDF仍應標示「模擬比較」，不能更換成實機研究題名或將模型數字當作實測數字。
