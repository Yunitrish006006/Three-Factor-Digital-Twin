# 教授審閱摘要：機箱雙熱節點模型下五種風扇控制策略之模擬比較

我已依2027工程科技應用研討會的中文全文格式完成一篇四頁審閱稿。研究問題是：在相同假設機箱熱模型、負載與PWM限制下，固定PWM、PI、PID、LQR及MPC的追蹤誤差、風扇代價與超溫結果如何不同。全文採2026年10月26日已凍結的同一批模擬證據，未加入新回合或實機資料。

實驗先用每方法三組候選及三個校準種子選參，共45回合；凍結後以驗證、保留測試、指定參數失配及過載四組進行60個正式回合。每組三個種子，共12,600個時間步。保留測試組的平均追蹤MAE依固定PWM、PI、PID、LQR、MPC順序為2.3462、2.2964、2.2879、1.4104及1.4428°C。LQR比PID低38.35%，但假設風扇功率計算的代價代理高15.83%。指定失配組的平均MAE以MPC最低。過載組全部方法都有取樣超溫，MPC有一步因殘差高於接受門檻而回退。

我在正文同時報告不利結果與可解釋範圍。LQR/MPC使用名義模型和當下負載，PI/PID沒有模型前饋；現有設計沒有獨立介入這些因素，因此不能把誤差差異歸因於單一機制。風扇代價是10u³ W假設下的計算值，並非量測節能；模型也沒有實體機箱幾何、物理風扇曲線、感測雜訊或硬體安全試驗。過載容量分析指出模型設定下散熱能力不足，應以降載、風道或散熱器改進與實測再檢查。

請教授協助審閱三項學術判斷：本篇以共同協定比較作為會議貢獻是否足夠；模型與方法描述是否需要再加一項可驗證的消融；作者單位、通訊作者及投稿安排是否正確。逐回合60筆結果及80列主張對照已附於同資料夾；作者順序已確認為林昀佑、易昶霈、沈慧宇，通訊資料待補。
