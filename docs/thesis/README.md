## 命名與維護規則（後續新增檔案）

- 主線文件維持 `*_zh.md` 命名，避免同主題多版本散落。
- 同主題若有不同用途，後綴統一用 `outline`、`speaker_notes`、`draft`。
- 新檔建立後，請同步補上本導覽的連結，避免再次變得難找。
