- 所屬週次：2026-10-05 至 2026-10-11；實際開會日期未另確認。
- 來源：使用者轉述本週教授交代的事項。
- 狀態：`IN_PROGRESS`。場景／方法查證、溫度候選原型與下週 LQR 備稿已完成；實體設備驗證、完整模型遷移與口頭報告尚未完成。

## 教授交辦原意

1. 找到金屬片、導熱風管等裝置的場景，用來加強導熱。
2. 利用 MPC、LQR、PID、PI 等方法的優點，開始把自己的模型改到能在機箱使用。
3. 下週向教授介紹 LQR 是什麼，並報告一篇關於 LQR 的代表性論文。

**名詞確認（2026-10-06）：**原轉述為「LQZ」，使用者已明確確認指 LQR（Linear Quadratic Regulator，線性二次調節器）。以下待辦採確認後名稱。

## 待辦一：尋找能強化傳熱的裝置與應用場景

目標是找到能對應機箱熱源、傳熱路徑與散熱需求的具體場景，而不只列出裝置名稱。

以下為依交辦整理的執行拆解，並非教授逐字指定的實驗規格：

- [x] 蒐集金屬片、導熱風管等裝置的案例，記錄來源、使用場景及可取得的資料。
- [x] 整理熱源、金屬接觸面、風管與風扇的配置，說明熱量如何從熱源傳到散熱端。
- [x] 查明各裝置主要改善的是固體導熱、氣流引導或對流散熱；保留「加強導熱」的交辦原意，再依案例釐清實際機制。
- [x] 比較場景是否能取得溫度、熱源功率、風扇 PWM／RPM 等資料，以及能否進行可重現的操作與量測。
- [x] 選出適合機箱模型改進的候選場景，列出裝置配置、必要量測與尚缺條件。
- [ ] 取得實體裝置與量測資料，驗證金屬接觸／導流改動的實際效果。

預計交付：**裝置／場景比較表與一個候選場景說明**。候選需附來源與傳熱路徑；實際改善效果留待量測或模擬驗證。

## 待辦二：借鑑控制方法，改進自己的機箱模型

目標是研究各方法可借用的機制，再改進自己的模型及其決策流程，使其逐步具備機箱使用條件。不能把現有控制器比較直接當成自己的模型已完成改進。

以下為依交辦整理的執行拆解；可借鑑機制仍需文獻查證與適用性判斷：

- [x] 整理自己現有模型的輸入、輸出、物理參數、稀疏感測校正與候選動作預測流程，找出遷移到機箱時的缺口。
- [x] 查讀 MPC、LQR、PID、PI 的原始研究或官方方法文件，製作優點、限制、所需資訊與可借鑑機制比較表。
- [x] 檢視 MPC 的多步預測、操作限制與重新規劃，PI／PID 的誤差回授與穩態偏差修正，以及 LQR 的狀態與控制代價設計。
- [x] 選擇有明確用途的機制，區分「改進熱模型／狀態估測」與「改進控制／動作選擇」，說明如何接入自己的方法。
- [x] 將待辦一的裝置與傳熱路徑納入候選模型設計，列出需要辨識的參數及資料需求。
- [x] 實作前固定研究問題、比較基準、資料切分、調參預算與完成判準，再依專案研究 OpenSpec 流程開始修改。
- [x] 在溫度子問題候選原型比較名義物理、辨識物理、稀疏校正與控制消融；保留六步排序未優於 PI 的結果。
- [ ] 將候選流程整合到正式模型，處理實測辨識、不同設備／方程家族及完整三因子遷移。

預計交付：**控制方法借鑑表、自己的模型改進流程圖與事前驗證計畫**；具備資料與平台後，再交付最小原型及比較結果。
