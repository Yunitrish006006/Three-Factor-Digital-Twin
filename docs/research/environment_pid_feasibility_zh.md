# 環境參數 PID：文獻與資料啟動條件

日期：2026-09-08。狀態：探索性可行性筆記，尚未採用新方法、執行控制實驗或確認新穎性。本筆記不改變主稿方法與證據等級。

使用者要求：只有在釐清既有研究後才開始，且必須同時考慮資料能否使用。搜尋未命中不能視為「確定無人做過」。目前廣義環境參數 PID 已有直接先例，尚未達成啟動新方法實作的條件。

資料門檻：

1. 保存版本、來源、授權及 checksum，區分可讀取、可研究使用與可再散布。
2. 先指定控制目標是空氣或元件溫度；不能將 CPU 接面溫度當成空氣真值。
3. 確认環境輸入有足夠變化與同步量測；沒有濕度、風速或元件功率時，不把它們列為已可用輸入。PSU 總功率不等於 CPU 熱輸入，RPM 不等於 PWM 或風扇瓦數。
4. 依實際熱響應與致動器延遲檢查取樣間隔。既有閉迴路風扇紀錄有混雜，不能直接回放溫度來代表另一控制器的反事實結果。
5. 明確分開離線預測、模型模擬及實機介入。模擬優勢不能寫成實際節能；模型需有独立動態驗證與適用範圍。
6. E15 確認資料已開封，不再作新方法的獨立確認；調參使用指定開發資料，最終另留未用過的批次。所有比較保留退步案例。

## 當前決策

文獻新穎性與控制資料適用性均尚未通過。下一步限於具體差異與資料可行性審核，不啟動宣稱新穎的 PID 實作。後續若確定可檢驗的差異及可用資料，再依 research-first OpenSpec 建立協定，並同步主稿與簡報。
