# Portable graph evidence

These are byte-identical snapshots of derived local result JSON, not raw datasets. The source-to-published mapping, SHA256 and byte counts are in [published_graph_evidence.json](../published_graph_evidence.json). Rebuild with `python3 scripts/publish_graph_evidence.py` after intentional result changes. ResearchWorkspace resolves both reads and source links through the manifest. Frozen experiment artifacts remain unchanged.
