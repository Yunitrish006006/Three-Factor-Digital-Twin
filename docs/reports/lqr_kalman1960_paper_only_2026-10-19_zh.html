這篇論文究竟研究什麼？

論文關心的是：對一個線性動態系統，如何選擇控制輸入，使整段時間累積的損失最小？

  • 使用狀態空間表達系統動態與可觀測輸出。
  • 使用二次型損失衡量狀態及操作代價。
  • 從最優性條件建立Riccati 型方程，討論最優回授及相關條件。
  • 處理可控性、可觀測性、存在性與穩定性的關係。

原文定位：p.102–103（問題與線性系統）、p.111–114（二次損失、Riccati 與定理）。

逐頁講稿／如何口頭解釋

可以先強調這不是一篇電子設備或機械實驗論文，而是最優控制理論研究。所謂最優，也不是任何意義下都最好，而是相對於研究者指定的動態模型與成本。原文的數學設定包含時變情況；今天常用的定常 LQR 是其中一條教學上方便理解的主線。

控制和狀態估測不是同一件事

狀態估測

當某些狀態不能直接知道時，使用觀測推估 x。

主要問題：「我目前在什麼狀態？」

控制設計

給定可用狀態，決定如何選擇 u。

主要問題：「下一步應採取什麼操作？」

Kalman 在原文 p.104 將估測與控制問題分開討論，並在所討論的控制設計部分先假設狀態精確已知。

因此不要把 Kalman filter、LQR 和 LQG 說成同一種演算法。
逐頁講稿／如何口頭解釋

如果教授問這篇是不是在講 Kalman Filter，我會回答：不是。這篇選讀論文的重點是最優控制。Kalman 相關研究還包括估測，但這裡在推導控制部分時，先以狀態已知為前提。狀態估測與控制是兩個不同的設計問題。

什麼叫做「最優」？先指定二次成本

J = ∫₀^∞ [ x(t)ᵀQx(t) + u(t)ᵀRu(t) ] dt
xᵀQx

狀態偏離理想值的懲罰；Q 指定哪些偏差更重要。

uᵀRu

操作投入的懲罰；R 指定過大控制的代價。

平方代表正負偏差都會產生代價，較大的偏差一般會受到更重的懲罰。

這是現代的定常、無限時域、零原點、無硬限制教學模型。原文 p.111 的 (A1) 是相應的二次損失假設，但記號、時間設定與輸出權重形式不同。Q 通常為半正定、R 為正定。

逐頁講稿／如何口頭解釋

最優控制不是只讓 x 變小，而是在「狀態偏差」與「控制代價」之間取平衡。若只希望偏差立刻變小，可能要求非常大的控制。成本同時懲罰控制量，避免不合理的無限大輸入。Q、R 是成本權重矩陣；這些字母不是 LQR 名稱逐字對應的縮寫。

念 Linear Quadratic Regulator，翻成線性二次調節器。L 指線性動態，Quadratic 指成本使用平方形式，Regulator 指根據系統狀態進行調節。公式裡的 Q、R 又是傳統常用符號，兩件事分開記。

Riccati 方程原本是什麼？

Riccati 方程是一類含有未知量二次項的非線性方程，比線性方程多了一個關鍵的平方項。

線性一階微分方程
y′ = b(t)y + c(t)
典型標量 Riccati 微分方程
y′ = a(t)y² + b(t)y + c(t)

最優控制會出現它的矩陣版本：未知數由一個數 y 變成一個矩陣 P。

背景教學補充：Riccati 方程遠早於 Kalman 1960 年的論文；此式不是該論文原式。

逐頁講稿／如何口頭解釋

先回答 Riccati 是什麼。一般線性微分方程的未知量只到一次，Riccati 類方程出現 y 的平方，所以本質上是非線性的。Kalman 沒有發明 Riccati 方程；最優控制需要用到它的矩陣形式。這頁是為理解文獻補的數學背景，不能說原文就長成這個標量方程。

KALMAN · 1960　/　Riccati 的數學動機
8 / 18

為什麼未來的積分成本，可以寫成 xᵀPx？

關鍵有兩層：線性動態配上平方成本，會保留二次型結構；當狀態不只一個，二次型就以矩陣表示。

① 只有一個狀態：直接積分

ẋ(t) = −x(t)　⇒　x(t) = x₀e⁻ᵗ
J = ∫₀^∞ x(t)² dt
= x₀²∫₀^∞ e⁻²ᵗ dt = ½x₀²

無限時間的積分，變成現在狀態的平方乘上一個係數：

J = Px₀²，P = ½

② 有多個狀態：用矩陣表示二次式

x = [x₁, x₂]ᵀ
V(x) = ax₁² + 2bx₁x₂ + cx₂²
P = [[a, b], [b, c]]
V(x) = xᵀPx

矩陣 P 不只表達各個狀態的平方項，也能表達 x₁x₂ 的交叉影響。

重要釐清：不是因為有 A、B 兩個因子才需要矩陣。x 的維度決定 P 的維度（n 個狀態 ⇒ n×n 的 P）；A、B 負責描述狀態動態與控制輸入。只有一個狀態時，A、B、P 都可以是純量。

③ 為什麼「最優」未來成本也能是二次型？

對線性系統 ẋ = Ax + Bu 和二次即時成本 xᵀQx + uᵀRu，先嘗試最優未來成本 V(x)=xᵀPx。代入最優性方程、對 u 取最小值並驗證適當條件後，會得到 Riccati 方程來求 P；下一頁展示詳細最小化步驟。

AᵀP + PA − PBR⁻¹BᵀP + Q = 0

Q 是即時狀態成本的指定權重；P 是考慮系統動態與最優控制後求得的「未來累積成本」係數，兩者不同。

展開完整推導：一維積分 → 多維矩陣 → HJB → Riccati

步驟 A：把無限遠積分真的算完

這個例子不包含控制輸入，先幫助理解「為什麼積分會變成現在狀態的平方」。假設 ẋ(t)=−x(t)、x(0)=x₀，則 x(t)=x₀e⁻ᵗ。

J = ∫₀^∞ (x₀e⁻ᵗ)² dt
= x₀² ∫₀^∞ e⁻²ᵗ dt
= x₀² · ½ = ½x₀²

因為 x₀ 對積分變數 t 是常數，可以提出積分之外。這裡 P=½，但這個數值只屬於本例。

步驟 B：把兩個狀態的二次式整理成矩陣

當 x=[x₁,x₂]ᵀ，最一般的實數對稱二次式可寫成 ax₁²+2bx₁x₂+cx₂²，而對稱矩陣 P=[[a,b],[b,c]] 可同時記錄平方項與交叉項。xᵀPx 是二次式的矩陣記號，並不是「多了兩個係數 A、B」才產生。

步驟 C：驗證最優控制下的二次型

對 ẋ=Ax+Bu、ℓ(x,u)=xᵀQx+uᵀRu，設 V(x)=xᵀPx，代入定常無限時域 HJB：

0 = minᵤ {xᵀQx + uᵀRu + 2xᵀP(Ax+Bu)}

對 u 微分、令其為零（R 正定）：

2Ru + 2BᵀPx = 0
u* = −R⁻¹BᵀPx = −Kx

再代入原來的 HJB，要求對所有 x 成立，得到：

AᵀP + PA − PBR⁻¹BᵀP + Q = 0

在 Q 半正定、R 正定，以及相關可穩定／可偵測等適當條件下，選擇穩定化解、確認閉迴路穩定，才能將此二次函數確認為最小未來成本；不能只靠寫下 V=xᵀPx 就宣稱已證明。

步驟 D：不要混淆即時成本與未來成本

xᵀQx：當下的狀態偏差成本。uᵀRu：當下的操作成本。J=∫₀^∞(xᵀQx+uᵀRu)dt：整段時間累積的成本。V(x)=xᵀPx：從目前狀態開始，採取最優控制後的最小未來成本。

有限時域時，最優成本通常寫作 V(t,x)=xᵀP(t)x，P(t) 隨時間改變；本頁主式是定常無限時域 CARE 的現代教學形式。

一維積分為說明二次型來源的基礎例子，並非對有控制輸入的最佳化問題作完整證明。多維 HJB 與 CARE 是現代定常 LQR 教學整理；原文 p.111–113 採不同符號與問題形式。

逐頁講稿／如何口頭解釋

為什麼未來從現在積分到無限遠的成本，可以寫成 x 轉置乘 P 乘 x？我先用一個沒有控制輸入的一維例子。假設 x 的微分等於負 x，則 x(t) 等於 x0 乘上 e 的負 t 次方。把狀態平方從零積到無限大，由於 x0 是常數，可以提出去；e 的負 2t 次方積分結果為二分之一，所以總成本剛好是二分之一乘上 x0 平方。這說明了積分可以變成『目前狀態的平方乘上一個係數』。接著如果系統有兩個狀態 x1 和 x2，最一般的二次式還可能包含兩個狀態的交叉項 2b x1 x2。要把這個二次式簡潔表達，就使用 x 轉置乘 P 乘 x，其中 P 是對稱矩陣。不是因為有 A 和 B 兩個因子才需要矩陣，而是因為 x 有多個狀態分量。最後，對真正有控制輸入的 LQR，線性動態加上二次成本使我們可以先提出二次型最優成本候選，再代入 HJB，對 u 最小化並解 Riccati 方程，在適當條件下驗證。Q 是當下狀態成本的權重；P 才是最優未來成本的二次型係數。下一頁我會展開最優化導出 u 等於負 Kx 的步驟。

用最優性原理一步步導出控制規則

對 ẋ=Ax+Bu 和 V=xᵀPx，在定常無限時域下，將「當下成本」與「未來成本變化」相加：

0 = minᵤ { xᵀQx + uᵀRu + 2xᵀP(Ax + Bu) }

只對可選的 u 微分並令結果為零：

2Ru + 2BᵀPx = 0
u* = −R⁻¹BᵀPx

定義回授增益 K=R⁻¹BᵀP，便得到：

u* = −Kx

這是以 Hamilton–Jacobi–Bellman 最優性條件示意的現代推導；不是 Kalman 原文逐行轉寫。R 正定確保上述對 u 的二次最小化有唯一解。

逐頁講稿／如何口頭解釋

要讓教授看懂為什麼會出現 Riccati，我不會突然丟結果。第一步：假設未來最小成本 V 等於 x^TPx。第二步：依最優性原理，當下狀態成本 x^TQx、操作成本 u^TRu，加上 V 隨時間的變化，最佳時要等於零。因為 V 對 x 微分是 2Px，V 的時間導數就是 2x^TP(Ax+Bu)。第三步：把 u 當成選擇變數，對 u 微分等於零，得到 u=-R^{-1}B^TPx。定義 K 就是 u=-Kx。這時 P 還不知道，所以仍要解 Riccati。

代回去，就得到 Riccati 方程

AᵀP + PA − PBR⁻¹BᵀP + Q = 0

CARE：Continuous-time Algebraic Riccati Equation，連續時間代數 Riccati 方程。

已知
  • A、B：動態模型
  • Q、R：成本權重
要解
  • P：最優成本二次型矩陣
  • 進一步 K=R⁻¹BᵀP
A、B、Q、R → 解 CARE 得 P → 計算 K → u=−Kx

這裡寫的是現代定常、無限時域、無限制 CARE。原文第 112 頁 (6.3) 為相關 Riccati 型方程，形式與符號不同，不能稱兩式逐字相同。

逐頁講稿／如何口頭解釋

把剛剛求出的最適控制 u 代回最優性式，讓關係對所有 x 成立，就得到這個矩陣方程。它看起來有 P 出現兩次，也有 P 左右相乘，所以是一個非線性的矩陣方程。它的任務很明確：已知 A B Q R，求 P。然後用 P 算 K。這就是 Riccati 方程在 LQR 裡的核心用途。

算給你看：只用一個狀態的例子

以下為自行設計的教學算例，不屬於 Kalman 1960 論文的實驗。

動態
ẋ = x + u
成本
J = ∫₀^∞ (x²+u²)dt
代入

A=1、B=1、Q=1、R=1。

2P − P² + 1 = 0
P² − 2P − 1 = 0

二次方程的根：P = 1 ± √2。選擇使閉迴路穩定的非負解：

P = 1 + √2 ≈ 2.414

因此 K = R⁻¹BᵀP = 2.414。

逐頁講稿／如何口頭解釋

算例是教大家真的能自己算，而不是只背矩陣。設定微分方程 xdot=x+u，這個系統本來會因為正的 x 項而偏離原點。成本把狀態與操作各自平方相加。A B Q R 都是 1，CARE 直接變成 2P-P^2+1=0。解出兩個根，選擇正根 P≈2.414；P 的選擇要滿足穩定化條件，不是任意選一個。

算例最後一步：K 如何讓系統穩定？

u* = −2.414x

把控制代回原本的系統：

ẋ = x − 2.414x = −1.414x = −√2 x

解為 x(t)=x(0)e−√2 t，所以時間愈長，狀態愈接近 0。

重點：我們不只解出了 P，而是使用 P 得到 K，再把 K 放回系統，確認閉迴路的動態。

此例沒有硬體、控制幅度限制或模型失配，不能直接將其穩定結果推論到所有真實系統。

逐頁講稿／如何口頭解釋

最後 u=-Kx=-2.414x。這代表 x 若是正數，會施加負的控制。代回去得 xdot=-1.414x，解是指數衰減，所以符合我們想把 x 調回零的目的。這一步證明這個教學例子裡的回授確實穩定，但仍不是說所有 LQR 配置都無條件穩定。

DRE、CARE、DARE 不是同一個式子

DRE｜微分 Riccati 方程
−Ṗ = AᵀP + PA − PBR⁻¹BᵀP + Q

常見於有限時域；P 隨時間變動，還須指定終端條件 P(T)。

CARE｜連續時間代數 Riccati 方程
AᵀP + PA − PBR⁻¹BᵀP + Q = 0

定常、無限時域條件下尋求不隨時間變的 P。

DARE｜離散時間代數 Riccati 方程
P = AᵀPA − AᵀPB(R+BᵀPB)⁻¹BᵀPA + Q

對離散動態 x[k+1]=Ax[k]+Bu[k]，其 K=(R+BᵀPB)⁻¹BᵀPA。

A、B 在離散方程指離散系統矩陣。公式為現代標準形式，不將它們冒稱為原文同一式。

逐頁講稿／如何口頭解釋

穩定性定理有條件，不能直接說保證最優

原文 p.114 有穩定性定理 (6.10)，其適用依賴系統和成本的條件；不是只要代進 Riccati 就自動安全。

  • 線性系統模型與定理的時間／可控觀測假設要相符。
  • 成本矩陣的正定性或相應的可偵測條件不能忽略。
  • 需選到適當的穩定化解，並確認閉迴路穩定。
  • 有控制飽和、動態不符模型、額外限制時，不能直接沿用原無限制最優保證。
「最優」永遠要接上一句：相對於哪一個模型、哪一個成本、哪些條件？

現代 LQR 的可穩定／可偵測條件是教學對照，不宣稱與原文 p.114 定理的全部假設逐字一致。

逐頁講稿／如何口頭解釋

教授若問 Riccati 解算出來就一定穩定嗎，我不能只回答是。需要檢查系統與成本滿足相應條件、選到穩定化的 P，控制後的 A-BK 也應檢驗穩定性。原文 p.114 不是對所有非線性和受限系統作保證。這是論文的數學邊界。

一分鐘口頭報告：今天我要介紹 Kalman 在 1960 年發表的《Contributions to the Theory of Optimal Control》。這篇論文主要研究：對線性動態系統，如何選擇控制輸入，使狀態偏差與控制投入的累積成本最小。 在理論上，它從狀態空間與二次損失討論最優控制，並連結 Riccati 型方程和最優回授。以現代定常 LQR 的公式說明，就是先由 A、B 描述動態、Q、R 指定成本權重，再解 Riccati 方程得到最小未來成本矩陣 P；利用 P 算回授增益 K，最後用 u=−Kx 計算控制輸入。 除此之外，原文也研究可控性、可觀測性，以及最優解存在和穩定性等理論問題。要注意，「最優」是相對於指定模型、成本及假設；必須選到適當的穩定化解。若模型不準、控制輸入受到硬限制，或使用的狀態估測有誤差，原本的理想結果不能不經檢查就套用到實際系統。

研究目的與成本

  • 什麼叫最優？　在指定線性動態、二次成本與可行條件下，使狀態偏差與控制輸入的「整段累積成本」最小；不是讓時間最小，也不代表成本一定是零。
  • Q、R、P 分別是什麼？　Q 懲罰即時狀態偏差 xᵀQx；R 懲罰即時控制輸入 uᵀRu；P 是由系統模型 A、B 與成本權重 Q、R，透過 Riccati 方程決定的最優未來成本二次型係數。
  • R 相對於 Q 變大，會怎樣？　控制輸入的代價變高，通常會傾向更保守、較小的控制量；不是 Q 或狀態偏差變得更大。
  • 為什麼無限積分能寫成 xᵀPx？　線性動態使未來狀態對目前狀態呈線性依賴，二次成本使累積式保留二次結構；在適當假設下透過 HJB 驗證二次型最優值函數與 Riccati 解。直觀例：ẋ=−x，∫₀^∞x(t)²dt=½x₀²。
  • 為什麼 P 要用矩陣？　多個狀態的二次成本包含平方項及可能的交叉項；例如 ax₁²+2bx₁x₂+cx₂²=xᵀPx。這不是因為有 A、B 兩個係數，交叉項也不代表動態一定直接耦合。

Riccati、回授與穩定

  • Riccati、P、K、u 的順序？　先由已知 A、B、Q、R 解 CARE 求 P，再算 K=R⁻¹BᵀP，最後 u=−Kx。P 描述成本，不等於直接施加的控制輸入；K 是回授增益，不是每一步重新做整條軌跡預測。
  • 負號的用途？　在如 ẋ=u、K>0 的例子，負回授可把偏差往原點修正；但一般多維系統需檢查閉迴路 A−BK 的特徵值，負號本身不等於保證穩定。
  • 一維 Riccati 怎麼來？　對 f(u)=Ru²+2BPxu 微分：2Ru+2BPx=0，所以 u*=−BPx/R；代回 HJB 的兩個控制項得到 −B²P²x²/R，再提出 x²，獲得 Q+2AP−B²P²/R=0。
  • 為什麼不能任選 Riccati 代數解？　要選滿足適當假設的穩定化解，並驗證 A−BK；例如 ẋ=x+u、Q=3、R=1 時 P=3 或 −1，但只有 P=3 導致 ẋ=−2x 穩定。
  • 有限時域的 P 為何是 P(t)？　從不同時間 t 到固定終點 T 的剩餘時間不同，即使 Q、R 不變，剩餘最優成本也可能不同；有限時域解微分 Riccati 方程，定常無限時域常用代數 CARE。

原文定位、控制與估測

  • Kalman 1960 是否就是 Kalman Filter？　不是。本文所報告的 Contributions to the Theory of Optimal Control 是最優控制理論；另外一篇 1960 年 A New Approach to Linear Filtering and Prediction Problems 是狀態估測代表文獻。
  • Kalman Filter 和 LQR 怎麼分工？　前者根據量測及模型估測狀態 x̂；後者在狀態可用時決定控制輸入，例如 u=−Kx̂。報告的原文 p.104 對控制設計先採取狀態精確已知的假設。
  • 可控性和可觀測性？　可控性：輸入能否在有限時間內把狀態移到指定位置；可觀測性：能否從一段時間的輸出及已知模型／輸入唯一重建初始狀態。可控不要求先可觀測。
  • 可穩定性和可偵測性？　可穩定：不可控的模態本身必須穩定；可偵測：不可觀測的模態本身必須穩定。這是現代 LQR 理論的常用教學對照，不等同於 1960 原文每個定理的逐字假設。
  • Kalman 1960 的重要內容？　狀態空間的最優控制問題、二次成本與 Riccati 型方程、可控性、可觀測性、解存在性與穩定性的討論；不能只說『它是有名的代表文獻』。
  • 為什麼原文不能直接說成現代 CARE？　原文包含時變與 Riccati 微分形式，現代 CARE 特指定常、無限時域的代數形式；符號、問題設定與適用條件並不逐字相同。

教授追問：理論界線

  • LQR 一定保證最優又穩定嗎？　不。需符合相應模型、成本、可穩定／可偵測等條件，選擇穩定化解；所謂最優只針對指定的數學問題。
  • 設備飽和時，截斷 u 就最優嗎？　若理想 u=−10，設備只允許 [−5,5]，截成 −5 只能確保輸入可執行，不保證飽和後系統仍最優或穩定；可能需要受限最佳化。
  • 有輸入限制就一定能穩定嗎？　不。例如 ẋ=x+u、|u|≤5、x=10，即使用 u=−5，ẋ=5 仍會朝外發散。
  • 模型誤差和估測誤差的差別？　模型誤差是設計用 A、B 和真實系統不同；估測誤差是 x̂ 和 x 不同。即使完美觀測，如果模型錯誤，按錯誤模型算出的 K 也可能使實際閉迴路不穩定。
  • 報告結語如何一句話說？　這篇論文將指定系統動態與成本的控制問題，轉成有數學條件支撐的最優回授分析；解出公式之後，仍必須檢查存在性、可控制觀測性及穩定性條件。
