**這份報告只討論論文及其數學背景。**教學算例與現代教科書記號會明確分開，不包含任何其他研究計畫的模型、資料或結果。

## 2. 這篇論文究竟研究什麼？（0:45–1:30）

論文關心的是：**對一個線性動態系統，如何選擇控制輸入，使整段時間累積的損失最小？**

- 使用**狀態空間**表達系統動態與可觀測輸出。

- 使用**二次型損失**衡量狀態及操作代價。

- 從最優性條件建立**Riccati 型方程**，討論最優回授及相關條件。

- 處理**可控性、可觀測性、存在性與穩定性**的關係。

原文定位：p.102–103（問題與線性系統）、p.111–114（二次損失、Riccati 與定理）。

> **口頭講稿：** 可以先強調這不是一篇電子設備或機械實驗論文，而是最優控制理論研究。所謂最優，也不是任何意義下都最好，而是相對於研究者指定的動態模型與成本。原文的數學設定包含時變情況；今天常用的定常 LQR 是其中一條教學上方便理解的主線。

## 3. 先認識「狀態」與「控制」（1:30–2:10）

```text
ẋ(t) = A(t)x(t) + B(t)u(t)
```

```text
y(t) = C(t)x(t)
```

**x(t)**

系統內部的狀態，可包含多個數值。
**u(t)**

操作者可以決定的輸入。

**A(t)**

在未施加新控制時，狀態如何演變。
**B(t)**

輸入如何影響狀態。
**y(t)、C(t)**

能觀察到的輸出與其映射。

此處為現代狀態空間寫法；原文 p.103 式 (2.1)–(2.2) 使用不同符號，概念相應。

> **口頭講稿：** x 不是位置座標，而是足以描述系統目前狀況的一組變數。A 和 B 是動態模型；C 告訴我們哪些狀態組合會被觀察到。原文對系統模型與輸出做區分。這一頁先不要急著求解控制器，先確定所有符號在描述什麼。

## 4. 控制和狀態估測不是同一件事（2:10–2:50）

### 狀態估測

當某些狀態不能直接知道時，使用觀測推估 x。

主要問題：「我目前在什麼狀態？」

### 控制設計

給定可用狀態，決定如何選擇 u。

主要問題：「下一步應採取什麼操作？」

Kalman 在**原文 p.104** 將估測與控制問題分開討論，並在所討論的控制設計部分先假設**狀態精確已知**。

因此不要把 **Kalman filter**、**LQR** 和 **LQG** 說成同一種演算法。

> **口頭講稿：** 如果教授問這篇是不是在講 Kalman Filter，我會回答：不是。這篇選讀論文的重點是最優控制。Kalman 相關研究還包括估測，但這裡在推導控制部分時，先以狀態已知為前提。狀態估測與控制是兩個不同的設計問題。

## 5. 什麼叫做「最優」？先指定二次成本（2:50–3:40）

```text
J = ∫₀^∞ [ x(t)ᵀQx(t) + u(t)ᵀRu(t) ] dt
```

**xᵀQx**

狀態偏離理想值的懲罰；Q 指定哪些偏差更重要。

**uᵀRu**

操作投入的懲罰；R 指定過大控制的代價。

**平方**代表正負偏差都會產生代價，較大的偏差一般會受到更重的懲罰。

這是現代的定常、無限時域、零原點、無硬限制教學模型。原文 p.111 的 (A1) 是相應的二次損失假設，但記號、時間設定與輸出權重形式不同。Q 通常為半正定、R 為正定。

> **口頭講稿：** 最優控制不是只讓 x 變小，而是在「狀態偏差」與「控制代價」之間取平衡。若只希望偏差立刻變小，可能要求非常大的控制。成本同時懲罰控制量，避免不合理的無限大輸入。Q、R 是成本權重矩陣；這些字母不是 LQR 名稱逐字對應的縮寫。

## 6. LQR 三個字母到底代表什麼？（3:40–4:15）

**L** — Linear：線性動態

**Q** — Quadratic：二次成本

**R** — Regulator：調節器

**容易誤會：**「Quadratic」是成本的形式；而成本函數裡剛好又習慣用矩陣 **Q** 和 **R** 表示兩種權重。不能把 LQR 三個字母直接說成三個矩陣名稱。

有了系統模型與成本函數，下一步才是：**求解使 J 最小的回授規則**。

> **口頭講稿：** 念 Linear Quadratic Regulator，翻成線性二次調節器。L 指線性動態，Quadratic 指成本使用平方形式，Regulator 指根據系統狀態進行調節。公式裡的 Q、R 又是傳統常用符號，兩件事分開記。

## 7. Riccati 方程原本是什麼？（4:15–5:05）

Riccati 方程是一類含有**未知量二次項**的非線性方程，比線性方程多了一個關鍵的平方項。

線性一階微分方程

```text
y′ = b(t)y + c(t)
```

典型標量 Riccati 微分方程

```text
y′ = a(t)y² + b(t)y + c(t)
```

最優控制會出現它的**矩陣版本**：未知數由一個數 **y** 變成一個矩陣 **P**。

背景教學補充：Riccati 方程遠早於 Kalman 1960 年的論文；此式不是該論文原式。

> **口頭講稿：** 先回答 Riccati 是什麼。一般線性微分方程的未知量只到一次，Riccati 類方程出現 y 的平方，所以本質上是非線性的。Kalman 沒有發明 Riccati 方程；最優控制需要用到它的矩陣形式。這頁是為理解文獻補的數學背景，不能說原文就長成這個標量方程。

## 8. 為什麼未來的積分成本，可以寫成 xᵀPx？（5:05–5:55 精簡，延伸推導另計）

理解這個問題需要分開兩個層次：**（一）為什麼未來積分可能變成狀態的平方；（二）為什麼有多個狀態時必須使用二次型矩陣，而有控制輸入後又為什麼可沿用這個結構。**

### 8.1 一個狀態：真的把無限遠的積分算完

先看沒有控制輸入、自然衰減的一維系統：

\[
\dot{x}(t)=-x(t),\qquad x(t)=x_0e^{-t}.
\]

令未來累積的狀態成本為：

\[
J=\int_0^{\infty}x(t)^2\,dt
=\int_0^{\infty}(x_0e^{-t})^2\,dt.
\]

因為初始狀態 \(x_0\) 不隨積分變數 \(t\) 改變，可以把它提出：

\[
J=x_0^2\int_0^{\infty}e^{-2t}\,dt
=\frac{1}{2}x_0^2.
\]

所以此例可以寫成 \(J=Px_0^2\)，其中 \(P=\tfrac12\)。**原本是無限時間的積分，算完就只剩下初始狀態平方乘上係數。** 注意：這一維示例沒有控制，目的只是幫助理解二次型如何由線性動態與平方成本出現，還沒有證明 LQR 的最優性。

### 8.2 有多個狀態：二次式寫成 xᵀPx

若系統有兩個狀態：

\[
x=\begin{bmatrix}x_1\\x_2\end{bmatrix},
\qquad
V(x)=ax_1^2+2bx_1x_2+cx_2^2,
\]

定義對稱矩陣：

\[
P=\begin{bmatrix}a&b\\b&c\end{bmatrix},
\]

就有：

\[
\boxed{V(x)=x^TPx}.
\]

矩陣 P 同時記錄 x1、x2 的平方係數，以及它們之間的交叉項。**不是因為 A、B 這兩個模型係數才用矩陣，而是狀態 x 若有 n 個分量，P 就是 n×n 的矩陣；若 x 只有一個分量，A、B 和 P 都可以是純量。**

### 8.3 為什麼採取最優控制後，未來成本也能保留二次型？

LQR 有兩項特殊的數學結構：

- 線性系統：\(\dot{x}=Ax+Bu\)。
- 二次即時成本：\(\ell(x,u)=x^TQx+u^TRu\)。

可先嘗試候選最優成本 \(V(x)=x^TPx\)，再代入定常無限時域 Hamilton–Jacobi–Bellman（HJB）最優性方程：

\[
0=\min_u\left[x^TQx+u^TRu+2x^TP(Ax+Bu)\right].
\]

對 u 微分並令其為零（假設 R 正定）：

\[
2Ru+2B^TPx=0,
\qquad u^*=-R^{-1}B^TPx.
\]

再把這個 u* 代回 HJB，要求對所有 x 成立，得到 CARE：

\[
\boxed{A^TP+PA-PBR^{-1}B^TP+Q=0}.
\]

在 Q 半正定、R 正定、可穩定／可偵測等適當條件下，找到穩定化解並驗證最優性，就可確認二次型是最小未來成本，而不是任意假設。第九頁接續細講 HJB 對 u 的最小化。

### 8.4 Q、P 與四種成本的差別

| 表示式 | 意義 |
| --- | --- |
| \(x^TQx\) | 這一瞬間的狀態偏差成本 |
| \(u^TRu\) | 這一瞬間的控制成本 |
| \(J=\int_0^\infty(x^TQx+u^TRu)\,dt\) | 一段從現在到未來無限遠的累積成本 |
| \(V(x)=x^TPx\) | 從目前狀態出發、採最優控制後的最小未來累積成本 |

Q 是自己指定的即時成本權重；P 則由系統動態、Q/R 和最優性條件共同決定。有限時域常寫作 \(V(t,x)=x^TP(t)x\)，P 隨時間改變。

> **口頭講稿（精簡版）：** 我先用 xdot 等於負 x 的一維模型，把 x(t) 的平方從零積分到無限大，計算出二分之一乘 x0 平方，說明未來積分可以變成目前狀態的平方。若系統有多個狀態，二次式會有交叉項，因此用 x 轉置乘 P 乘 x 表示。需要矩陣的主因是 x 的維度，不是有 A、B 兩個因子。對真正的最優控制問題，線性動態加上二次成本，使候選的二次型最優成本可透過 HJB、Riccati 方程及必要條件驗證。Q 是即時狀態成本權重，P 是未來最小成本的係數。接下來再看如何從最小化推得 u 等於負 Kx。

> **原文關係：** 上述一維積分及現代 HJB/CARE 是協助理解 Kalman 1960 最優控制理論的數學整理，不代表原文逐字使用相同算例或符號。原文二次損失與 Riccati 分析定位在 p.111–113。

## 9. 用最優性原理一步步導出控制規則（5:55–7:05）

對 **ẋ=Ax+Bu** 和 **V=xᵀPx**，在定常無限時域下，將「當下成本」與「未來成本變化」相加：

```text
0 = minᵤ { xᵀQx + uᵀRu + 2xᵀP(Ax + Bu) }
```

只對可選的 **u** 微分並令結果為零：

```text
2Ru + 2BᵀPx = 0
```

```text
u* = −R⁻¹BᵀPx
```

定義**回授增益** **K=R⁻¹BᵀP**，便得到：

```text
u* = −Kx
```

這是以 Hamilton–Jacobi–Bellman 最優性條件示意的現代推導；不是 Kalman 原文逐行轉寫。R 正定確保上述對 u 的二次最小化有唯一解。

> **口頭講稿：** 要讓教授看懂為什麼會出現 Riccati，我不會突然丟結果。第一步：假設未來最小成本 V 等於 x^TPx。第二步：依最優性原理，當下狀態成本 x^TQx、操作成本 u^TRu，加上 V 隨時間的變化，最佳時要等於零。因為 V 對 x 微分是 2Px，V 的時間導數就是 2x^TP(Ax+Bu)。第三步：把 u 當成選擇變數，對 u 微分等於零，得到 u=-R^{-1}B^TPx。定義 K 就是 u=-Kx。這時 P 還不知道，所以仍要解 Riccati。

## 10. 代回去，就得到 Riccati 方程（7:05–7:55）

```text
AᵀP + PA − PBR⁻¹BᵀP + Q = 0
```

**CARE：Continuous-time Algebraic Riccati Equation**，連續時間**代數** Riccati 方程。

**已知**

- A、B：動態模型

- Q、R：成本權重

**要解**

- P：最優成本二次型矩陣

- 進一步 K=R⁻¹BᵀP

A、B、Q、R ：→  解 CARE 得 P ：→  計算 K ：→  u=−Kx

這裡寫的是現代定常、無限時域、無限制 CARE。原文第 112 頁 (6.3) 為相關 Riccati 型方程，形式與符號不同，不能稱兩式逐字相同。

> **口頭講稿：** 把剛剛求出的最適控制 u 代回最優性式，讓關係對所有 x 成立，就得到這個矩陣方程。它看起來有 P 出現兩次，也有 P 左右相乘，所以是一個非線性的矩陣方程。它的任務很明確：已知 A B Q R，求 P。然後用 P 算 K。這就是 Riccati 方程在 LQR 裡的核心用途。

## 11. 算給你看：只用一個狀態的例子（7:55–9:00）

以下為**自行設計的教學算例**，不屬於 Kalman 1960 論文的實驗。

**動態**

```text
ẋ = x + u
```

**成本**

```text
J = ∫₀^∞ (x²+u²)dt
```

**代入**

A=1、B=1、Q=1、R=1。

```text
2P − P² + 1 = 0
```

```text
P² − 2P − 1 = 0
```

二次方程的根：**P = 1 ± √2**。選擇使閉迴路穩定的非負解：

```text
P = 1 + √2 ≈ 2.414
```

因此 **K = R⁻¹BᵀP = 2.414**。

> **口頭講稿：** 算例是教大家真的能自己算，而不是只背矩陣。設定微分方程 xdot=x+u，這個系統本來會因為正的 x 項而偏離原點。成本把狀態與操作各自平方相加。A B Q R 都是 1，CARE 直接變成 2P-P^2+1=0。解出兩個根，選擇正根 P≈2.414；P 的選擇要滿足穩定化條件，不是任意選一個。

## 12. 算例最後一步：K 如何讓系統穩定？（9:00–9:35）

```text
u* = −2.414x
```

把控制代回原本的系統：

```text
ẋ = x − 2.414x = −1.414x = −√2 x
```

解為 **x(t)=x(0)e^(−√2 t)**，所以時間愈長，狀態愈接近 0。

**重點：**我們不只解出了 P，而是使用 P 得到 K，再把 K 放回系統，確認閉迴路的動態。

此例沒有硬體、控制幅度限制或模型失配，不能直接將其穩定結果推論到所有真實系統。

> **口頭講稿：** 最後 u=-Kx=-2.414x。這代表 x 若是正數，會施加負的控制。代回去得 xdot=-1.414x，解是指數衰減，所以符合我們想把 x 調回零的目的。這一步證明這個教學例子裡的回授確實穩定，但仍不是說所有 LQR 配置都無條件穩定。

## 13. DRE、CARE、DARE 不是同一個式子（9:35–10:25）

**DRE｜微分 Riccati 方程**

```text
−Ṗ = AᵀP + PA − PBR⁻¹BᵀP + Q
```

常見於有限時域；P 隨時間變動，還須指定終端條件 P(T)。

**CARE｜連續時間代數 Riccati 方程**

```text
AᵀP + PA − PBR⁻¹BᵀP + Q = 0
```

定常、無限時域條件下尋求不隨時間變的 P。

**DARE｜離散時間代數 Riccati 方程**

```text
P = AᵀPA − AᵀPB(R+BᵀPB)⁻¹BᵀPA + Q
```

對離散動態 x[k+1]=Ax[k]+Bu[k]，其 K=(R+BᵀPB)⁻¹BᵀPA。

A、B 在離散方程指離散系統矩陣；公式為現代標準形式，不將它們冒稱為原文同一式。

> **口頭講稿：** 這一頁用來避免教授追問時混淆。DRE 是有 P 的時間導數，通常有限時域從終端往回解；CARE 是定常連續時間的代數式，沒有 Pdot；DARE 對應離散時間，例如電腦每隔固定時間計算一次控制，公式多出 R+B^TPB。原文以時變最優控制為重要範圍，不能只用現代 CARE 假裝涵蓋全文。

## 14. 可控性與可觀測性：兩個不同問題（10:25–11:05）

**可控性 Controllability**

控制輸入能否在有限時間內把狀態從一個位置帶到另一個指定位置？

對 n 維定常線性系統，常見檢查：

```text
rank[B AB ··· Aⁿ⁻¹B]=n
```

**可觀測性 Observability**

能否從一段輸出 y 的時間資訊，唯一確定初始狀態？

對 n 維定常線性系統，常見檢查：

```text
rank[Cᵀ (CA)ᵀ ··· (CAⁿ⁻¹)ᵀ]=n
```

原文：p.108 的可控性 rank 條件 (5.6)，p.111 的可觀測性定義 (5.23)。此處的兩個矩陣表示法為現代定常系統教學整理。

> **口頭講稿：** 可控性問的是『輸入能控制到哪些狀態』；可觀測性問的是『輸出能反推出哪些狀態』。一個系統可以部分可控卻未必可觀測，也可以相反。LQR 的穩定化常用條件比較弱，叫可穩定、可偵測；不能把它們和完全可控、完全可觀測混為一談。

## 15. 穩定性定理有條件，不能直接說保證最優（11:05–11:50）

原文 p.114 有**穩定性定理 (6.10)**，其適用依賴系統和成本的條件；不是只要代進 Riccati 就自動安全。

- 線性系統模型與定理的時間／可控觀測假設要相符。

- 成本矩陣的正定性或相應的可偵測條件不能忽略。

- 需選到適當的**穩定化解**，並確認閉迴路穩定。

- 有控制飽和、動態不符模型、額外限制時，不能直接沿用原無限制最優保證。

「最優」永遠要接上一句：**相對於哪一個模型、哪一個成本、哪些條件？**

現代 LQR 的可穩定／可偵測條件是教學對照，不宣稱與原文 p.114 定理的全部假設逐字一致。

> **口頭講稿：** 教授若問 Riccati 解算出來就一定穩定嗎，我不能只回答是。需要檢查系統與成本滿足相應條件、選到穩定化的 P，控制後的 A-BK 也應檢驗穩定性。原文 p.114 不是對所有非線性和受限系統作保證。這是論文的數學邊界。

## 附錄 A｜完成 28 題問答後的口頭報告修正版（2026-10-19）

> **適用範圍**：這個附錄只回顧 Kalman 1960 最優控制代表論文、現代 LQR 教學形式和本次答辯練習，不涉及其他專案或模擬結果。
>
> **原文與教學分界**：原論文 p.103–104 有狀態空間與控制／估測的討論，p.111–114 包括二次成本、Riccati 型方程、理論條件；以下的 CARE、HJB、標量例題是現代教學整理，不把它們冒稱原文逐字公式。

### A1. 一分鐘講稿（按本次最後複試修正）

今天我要介紹 Kalman 在 1960 年發表的《Contributions to the Theory of Optimal Control》。這篇論文主要研究：對線性動態系統，如何選擇控制輸入，使狀態偏差與控制投入的累積成本最小。

在理論上，它從狀態空間與二次損失討論最優控制，並連結 Riccati 型方程和最優回授。以現代定常 LQR 的公式說明，就是先由 A、B 描述動態、Q、R 指定成本權重，再解 Riccati 方程得到最小未來成本矩陣 P；利用 P 算回授增益 K，最後用 u=−Kx 計算控制輸入。

除此之外，原文也研究可控性、可觀測性，以及最優解存在和穩定性等理論問題。要注意，「最優」是相對於指定模型、成本及假設；必須選到適當的穩定化解。若模型不準、控制輸入受到硬限制，或使用的狀態估測有誤差，原本的理想結果不能不經檢查就套用到實際系統。

### A2. 口頭答辯快速複習：我最容易混淆的幾點

1. **狀態成本 ≠ 時間成本**：Q 懲罰 x，R 懲罰 u；積分只是把各時刻的成本累積起來。
2. **P ≠ Q/R ≠ K**：A、B、Q、R → Riccati 解 P（描述最小未來累積成本）→ K（回授增益）→ u=−Kx（控制輸入）。
3. **為什麼是 xᵀPx？**：先分清「無限積分變成二次式」與「多維二次式寫成矩陣」是兩個不同的問題。
4. **最優 ≠ 必然收斂**：不是任意的 Riccati 代數解都能用；要選穩定化解並查驗閉迴路。
5. **估測 ≠ 控制**：Kalman Filter 估測 x̂；LQR 根據狀態決定 u。模型誤差（A、B 錯）也不等於估測誤差（x̂ 錯）。
6. **完全可控 ≠ 可穩定、完全可觀測 ≠ 可偵測**：無法控制／無法觀測的模態仍可存在，但必須本來穩定。
7. **控制幅度合規 ≠ 控制穩定**：把 u 裁切進設備允許範圍並不保證最優或收斂。
8. **原始 1960 論文 ≠ 整本現代 LQR 教科書**：原文有時變設定和相關定理；現代 CARE 及例題只是解釋方便。

### A3. 教授問答速查（本次答題的正確觀念，不是原逐字問答紀錄）

#### A3.1 研究目的與成本

**Q1.1｜什麼叫最優？**

在指定線性動態、二次成本與可行條件下，使狀態偏差與控制輸入的「整段累積成本」最小；不是讓時間最小，也不代表成本一定是零。

**Q1.2｜Q、R、P 分別是什麼？**

Q 懲罰即時狀態偏差 xᵀQx；R 懲罰即時控制輸入 uᵀRu；P 是由系統模型 A、B 與成本權重 Q、R，透過 Riccati 方程決定的最優未來成本二次型係數。

**Q1.3｜R 相對於 Q 變大，會怎樣？**

控制輸入的代價變高，通常會傾向更保守、較小的控制量；不是 Q 或狀態偏差變得更大。

**Q1.4｜為什麼無限積分能寫成 xᵀPx？**

線性動態使未來狀態對目前狀態呈線性依賴，二次成本使累積式保留二次結構；在適當假設下透過 HJB 驗證二次型最優值函數與 Riccati 解。直觀例：ẋ=−x，∫₀^∞x(t)²dt=½x₀²。

**Q1.5｜為什麼 P 要用矩陣？**

多個狀態的二次成本包含平方項及可能的交叉項；例如 ax₁²+2bx₁x₂+cx₂²=xᵀPx。這不是因為有 A、B 兩個係數，交叉項也不代表動態一定直接耦合。


#### A3.2 Riccati、回授與穩定

**Q2.1｜Riccati、P、K、u 的順序？**

先由已知 A、B、Q、R 解 CARE 求 P，再算 K=R⁻¹BᵀP，最後 u=−Kx。P 描述成本，不等於直接施加的控制輸入；K 是回授增益，不是每一步重新做整條軌跡預測。

**Q2.2｜負號的用途？**

在如 ẋ=u、K>0 的例子，負回授可把偏差往原點修正；但一般多維系統需檢查閉迴路 A−BK 的特徵值，負號本身不等於保證穩定。

**Q2.3｜一維 Riccati 怎麼來？**

對 f(u)=Ru²+2BPxu 微分：2Ru+2BPx=0，所以 u*=−BPx/R；代回 HJB 的兩個控制項得到 −B²P²x²/R，再提出 x²，獲得 Q+2AP−B²P²/R=0。

**Q2.4｜為什麼不能任選 Riccati 代數解？**

要選滿足適當假設的穩定化解，並驗證 A−BK；例如 ẋ=x+u、Q=3、R=1 時 P=3 或 −1，但只有 P=3 導致 ẋ=−2x 穩定。

**Q2.5｜有限時域的 P 為何是 P(t)？**

從不同時間 t 到固定終點 T 的剩餘時間不同，即使 Q、R 不變，剩餘最優成本也可能不同；有限時域解微分 Riccati 方程，定常無限時域常用代數 CARE。


#### A3.3 原文定位、控制與估測

**Q3.1｜Kalman 1960 是否就是 Kalman Filter？**

不是。本文所報告的 Contributions to the Theory of Optimal Control 是最優控制理論；另外一篇 1960 年 A New Approach to Linear Filtering and Prediction Problems 是狀態估測代表文獻。

**Q3.2｜Kalman Filter 和 LQR 怎麼分工？**

前者根據量測及模型估測狀態 x̂；後者在狀態可用時決定控制輸入，例如 u=−Kx̂。報告的原文 p.104 對控制設計先採取狀態精確已知的假設。

**Q3.3｜可控性和可觀測性？**

可控性：輸入能否在有限時間內把狀態移到指定位置；可觀測性：能否從一段時間的輸出及已知模型／輸入唯一重建初始狀態。可控不要求先可觀測。

**Q3.4｜可穩定性和可偵測性？**

可穩定：不可控的模態本身必須穩定；可偵測：不可觀測的模態本身必須穩定。這是現代 LQR 理論的常用教學對照，不等同於 1960 原文每個定理的逐字假設。

**Q3.5｜Kalman 1960 的重要內容？**

狀態空間的最優控制問題、二次成本與 Riccati 型方程、可控性、可觀測性、解存在性與穩定性的討論；不能只說『它是有名的代表文獻』。

**Q3.6｜為什麼原文不能直接說成現代 CARE？**

原文包含時變與 Riccati 微分形式，現代 CARE 特指定常、無限時域的代數形式；符號、問題設定與適用條件並不逐字相同。


#### A3.4 教授追問：理論界線

**Q4.1｜LQR 一定保證最優又穩定嗎？**

不。需符合相應模型、成本、可穩定／可偵測等條件，選擇穩定化解；所謂最優只針對指定的數學問題。

**Q4.2｜設備飽和時，截斷 u 就最優嗎？**

若理想 u=−10，設備只允許 [−5,5]，截成 −5 只能確保輸入可執行，不保證飽和後系統仍最優或穩定；可能需要受限最佳化。

**Q4.3｜有輸入限制就一定能穩定嗎？**

不。例如 ẋ=x+u、|u|≤5、x=10，即使用 u=−5，ẋ=5 仍會朝外發散。

**Q4.4｜模型誤差和估測誤差的差別？**

模型誤差是設計用 A、B 和真實系統不同；估測誤差是 x̂ 和 x 不同。即使完美觀測，如果模型錯誤，按錯誤模型算出的 K 也可能使實際閉迴路不穩定。

**Q4.5｜報告結語如何一句話說？**

這篇論文將指定系統動態與成本的控制問題，轉成有數學條件支撐的最優回授分析；解出公式之後，仍必須檢查存在性、可控制觀測性及穩定性條件。
