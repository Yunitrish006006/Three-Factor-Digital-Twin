# 碩士論文研究進度週報

- 報告期間：2026 年 7 月 28 日至 8 月 3 日
- 研究主題：以稀疏感測建構單房間空間數位孿生，學習非連網設備的環境影響

## 一、本週研究重點

本週主要完成五項工作：整理真實臥室資料的不確定性分析、新增逐日剔除敏感度檢查、檢驗混合模型在次日溫度預測上的適用性、準備控制推薦的真實介入驗證流程，以及依教授建議完成 RNN 同資料比較並重新界定應用範圍。整體結果顯示，目前方法在單房間稀疏校正上具有穩定改善，但尚未證明可提升次日溫度預測；新增的 RNN 在公平比較中也沒有取得最低 MAE。研究應用暫時保留人體舒適的容許範圍式決策支援，並把 20–30 °C 內的動態封閉植物生長環境列為待驗證候選，而非直接宣稱可跨場域使用。

## 二、先前表現與改進後對比

### 1. 受控八情境的場重建表現

為呈現模型逐步改進的效果，下表比較傳統 IDW 插值、先前完成的設備感知 base model，以及加入 residual learning 後的 leave-one-scenario-out hybrid model。三者使用相同八組受控情境，數值皆為平均 field MAE，數值越低越好。

| 環境因子 | 傳統 IDW baseline | 先前 base model | 改進後 LOO hybrid | 相對先前 base model 的降幅 |
| --- | ---: | ---: | ---: | ---: |
| 溫度 | 0.1723 °C | 0.0474 °C | 0.0017 °C | 96.41% |
| 相對濕度 | 0.4633 %RH | 0.1765 %RH | 0.0059 %RH | 96.66% |
| 照度 | 54.9052 lux | 2.0269 lux | 0.1407 lux | 93.06% |

先前的設備感知 base model 相較 IDW，三項 MAE 已分別降低 72.47%、61.90% 與 96.31%；加入 hybrid residual correction 後，又在 leave-one-scenario-out 評估中相對 base model 降低 96.41%、96.66% 與 93.06%。這顯示設備物理結構先改善傳統空間插值的限制，residual learning 再修正剩餘的系統性誤差。

上述數字來自具有完整場真值的受控模擬，用於比較方法與檢查模型改進，不代表已在任意真實房間取得相同精度。真實臥室部分則以下一節的未校正與校正後 pillow 參考點結果作為獨立對照。

## 四、主要研究結果

### 1. 真實臥室稀疏校正

使用 7 天、28 個量測時點的臥室資料，並以未作為校正感測器的枕頭位置作為參考點。校正前後的平均絕對誤差如下：

| 環境因子 | 校正前 MAE | 校正後 MAE | 相對下降 |
| --- | ---: | ---: | ---: |
| 溫度 | 0.8967 °C | 0.1676 °C | 81.31% |
| 相對濕度 | 4.1286% | 0.3939% | 90.46% |
| 照度 | 309.0142 lux | 16.6450 lux | 94.61% |

進一步以日期為單位進行 20,000 次 paired block bootstrap，三項環境因子的誤差下降信賴區間下界皆大於 0。這支持稀疏感測校正在目前臥室、量測期間與參考位置上具有一致改善；但仍不能推廣為不同房間或完整三維場域的普遍結論。

本週再加入 7-fold leave-one-date-out 敏感度分析，每次移除一天的 4 筆資料，再以其餘 24 筆重算校正效果。七次分析中最保守的 MAE 降幅如下：

| 環境因子 | 逐日剔除後的最小 MAE 降幅 |
| --- | ---: |
| 溫度 | 0.6123 °C |
| 相對濕度 | 3.5551 %RH |
| 照度 | 290.5716 lux |

三項最小降幅均大於 0，表示目前結果不依賴保留某一個特定日期。這項本週新增工作沒有更換模型或重新宣稱一組更低的校正 MAE，而是檢查前述「校正前對校正後」的改善在移除任一天後是否仍成立。不過，七個分析 folds 使用的是同一房間、同一 pillow 參考點且資料高度重疊，因此只能視為內部敏感度檢查，不能當作七次獨立實驗或跨房間泛化證據。

### 2. 混合模型比較與次日溫度預測

在公開資料的相同切分與評估條件下，參考文獻架構建立的 additive residual 方法，在 6 個比較案例中有 4 個優於原始物理先驗。然而，在 1,440 分鐘的次日溫度預測上，改善並未成立。

另外執行的次日溫度候選模型比較顯示：主要方法相對 persistence baseline 的平均 MAE 變化為 `-7.85%`，探索性方法為 `-9.28%`，代表兩者皆比 persistence 差。因此目前不主張本研究方法具有次日預測優勢，並將此結果保留為方法適用範圍與限制。

### 3. 控制推薦介入驗證

目前已完成真實介入實驗所需的量測欄位、before/after 比較方式與分析流程。預定做法是先由模型提出候選動作排序，再實際執行排名第一的動作，比較介入前後的環境舒適度變化。

目前完成的真實介入試驗數仍為 0，因此現階段只能將控制輸出描述為「模型反事實推估下的推薦排序」，不能宣稱推薦已具有實測改善或因果效果。

### 4. 教授建議的 RNN 公平比較

本週在 SML2010 S2 的 dining/room 溫度與濕度上，加入固定 vanilla RNN，評估 15、60 與 1,440 分鐘三種預測時間。四種方法為 persistence、sequence linear regression、physics-structured readout 與 RNN；所有模型取得相同的四筆歷史資料、相同 chronological 70/30 split、相同 target 與相同 test rows。12/12 個案例通過資料一致性檢查。

| 最低 MAE 方法 | 案例數 |
| --- | ---: |
| Sequence linear regression | 7 / 12 |
| Persistence | 5 / 12 |
| Physics-structured readout | 0 / 12 |
| Vanilla RNN | 0 / 12 |

RNN 在兩個 60 分鐘溫度案例優於 persistence，但沒有任何案例優於 sequence linear regression，因此目前不能主張 recurrent structure 帶來整體優勢。這項結果仍有研究價值：它完成教授要求的比較，也顯示在目前資料量、四筆歷史與固定小型架構下，較複雜的模型不一定優於簡單基準。

### 5. 應用情境與 20–30 °C 邊界

教授指出，一般人體舒適多以範圍判定，未必需要非常窄的溫濕度控制。因此本週將人居情境調整為「目標值加容許範圍」的 decision support，不再由低 MAE 直接推論極精準控制有必要。

目前較合理的候選，是需要日夜或生長階段環境配方的小型封閉植物生長室／植物工廠模組；這類場景有動態溫度、濕度與光照變化的研究需求。然而，本研究現階段只涵蓋 20–30 °C，且 lux 不能取代植物 PPFD/PAR，另缺 CO2、基質水分、氣流與生物終點。因此只能把它列為下一階段候選，不宣稱目前系統已可用於植物培養，也不能延伸到超出 20–30 °C 的處理。

### 6. Kalman Filter 研究參考

Kalman Filter 較適合放在隨時間更新隱藏環境狀態、融合稀疏量測，或線上調整簡化物理模型參數的位置。相關溫室研究同時存在正向與負向結果：有研究顯示 EKF 可支援線上參數適應，也有研究發現 EKF、UKF 或移動平均未必改善監測，原因與基礎模型準確度高度相關。因此目前先保留為後續同資料比較方向，尚未列為已完成成果。

## 五、目前結論

1. 稀疏感測校正在目前單一臥室與 held-out 參考點上，可穩定降低溫度、濕度與照度估測誤差；逐日剔除結果也顯示正向改善不依賴保留某一特定日期。
2. 混合 residual 概念在部分短期案例能改善物理先驗，但目前未證明具有次日溫度預測優勢。
3. 控制推薦方法已具備實驗流程，但仍缺少真實介入資料，因果效果尚未驗證。
4. RNN 已在相同資料與測試列下完成比較，但最低 MAE 為 0/12；應保留此負向結果，不把模型複雜度當作改善證據。
5. 目前較適合將論文貢獻聚焦於「稀疏 IoT 感測、單房間空間校正、非連網設備影響建模與可解釋決策支援」，不把次日預測、自動控制或植物培養成效列為主要成果。
6. 任何新應用都必須先通過 20–30 °C 溫度範圍檢查；動態植物生長環境目前只是候選方向。

## 六、下週預定工作

1. 先定義一個全程落在 20–30 °C 的動態封閉環境最小情境，明確列出日夜 setpoint、濕度與光照變化。
2. 評估是否能補入 PPFD/PAR、CO2、基質水分與 actuator log；若不足，維持候選應用定位。
3. 為 Kalman Filter 定義 state、observation 與 noise covariance，再另行預註冊同資料實驗。
4. 視量測時程開始進行控制推薦的真實 before/after 介入試驗。
5. 保留 RNN 與次日預測的負面結果，不因模型名稱或複雜度調整結論。

1. 是否同意以「稀疏感測空間校正與設備影響建模」作為論文主要研究主線。

3. RNN 與次日預測的負面結果應保留在主要實驗結果中，或濃縮放入研究限制。
